# RO-World

เกมเบราว์เซอร์แนว MMORPG ย่อส่วน — เมืองพรอนเทรา, ทุ่งฟาร์ม, บอส 7 ตัว, PvP
ทุ่งเริ่มต้นเป็นธีมป่าสงบ.
**ทุ่ง = ต่อสู้เรียลไทม์บนแผนที่** (เดิน ล็อกเป้า ฟันอัตโนมัติ) · **บอส = เลือกจากรายการแล้วเข้าฉากเทิร์นเบส ATB** ไม่ต้องเดินชนบนแผนที่บอส

## วิธีเปิดเล่น
1. เปิด `index.html` ด้วยเบราว์เซอร์ หรือ
2. `python3 -m http.server 8080` หรือ `python3 server.py` (พอร์ต 8765 — ต้องใช้ถ้าเล่นห้อง PvP)

ทดสอบสูตร: `node tests/formulas.mjs`

## การต่อสู้
- **กล้อง 33×23 เต็มจอ (แนวนอน)** — ทุ่ง **100×100** procedural · **เมืองพรอนเทรา 80×80** เมืองกำแพงแบบยุโรป (ถนนหินคลุกชมพู-เทา ลานธงหิน + น้ำพุหลายช่อง บ้านหลังคาสีแดง โบสถ์หินอ่อน ปราสาททิศเหนือ ประตูทุ่งทิศตะวันออก) เดินได้ทั้งเมืองในกล้องเดียวกัน
- เรนเดอร์เฉพาะหน้าต่างกล้อง (+1 มาร์จิน) กล้องตามผู้เล่นทุกก้าว · คลิกเดินใช้ A* จำกัดโหนด / greedy ไม่ BFS ทั้งแมพ
- **เมืองพรอนเทรา = เซฟโซน** — ไม่ต่อสู้ NPC ทำงานเหมือนเดิม
- **ทุ่งพรอนเทรา** — มอนเป็นสไปรต์ 2.5D บนแผนที่ เดินชิดหรือคลิกเพื่อล็อกเป้า แล้ว**ฟันอัตโนมัติ** ตาม A.speed · สกิลฮอตคีย์ **1–6**
- **บอส** — เลือกบอสจากรายการ แล้วเข้าฉากเทิร์นเบส ATB (`UI.combat` + เกจ A.speed + ปุ่มสกิล) **ไม่ต้องเดินชนบนแผนที่บอส**
- HUD ขณะเดินทุ่ง: แถบ HP/MP เล็กบนสุด · สกิล 1–6 มุมขวาล่าง · ปุ่ม D-pad มุมซ้ายล่าง
- ทุ่ง: คูลดาวน์เป็นวินาทีจริง `cdSec = cdTurns * 1.6` (CD 0 = โกลบอล 0.3 วินาที)
- ยาจากกระเป๋าใช้ได้ตลอด · ตายแล้วเกิดที่พรอนเทรา HP 50% (EXP ไม่หาย) · แพ้บอสมีปุ่มเลือกบอสอีกครั้ง + กลับเมือง

### สูตรช่วงชักดาบ (ASPD)
`delayMs = clamp(380, 2000, round(1600 - A.speed * 22))`
A.speed สูง = ฟันเร็วขึ้น แสดงเป็นตัวเลข ASPD บน HUD ไม่ใช่เกจรอตา

### Auto Farm (ปุ่ม F / HUD)
เฉพาะทุ่ง: เดินเข้ามอนใกล้สุด ยืนชิด ฟันอัตโนมัติ + ใช้สกิลดาเมจเมื่อ CD พร้อม ดื่มยาแดง/ส้มเมื่อ HP < 40%
ถ้า HP < 15% และยาหมด — ปิด Auto Farm แล้ว toast

## โหมดผจญภัย (PvE) — ลำดับเล่น
1. เลือกฮีโร่ แล้วแจกแต้มเริ่มต้น **400** (STR VIT INT AGI DEX LUK)
2. จัดต้นไม้สกิล (เริ่ม 4 แต้ม, ราก 2 โหนดได้แรงก์ 1 ฟรี)
3. เกิดใน **เมืองพรอนเทรา** — ลานกลางเมืองด้านใต้ เห็นน้ำพุ ร้านอาวุธ/ร้านยา คาฟร้า โบสถ์ทางเหนือ และประตูทุ่งทิศตะวันออก
4. เดินเข้า NPC: **ร้านอาวุธ/อุปกรณ์**, **ร้านยา**, **คาฟร้า** (รักษา 50 Zeno) หรือกด **สู้บอส** / เดินเข้าปราสาทโลหิตเพื่อเปิดรายการบอส
5. ออกประตูทิศตะวันออกเข้า **ทุ่งพรอนเทรา** สู้โปริ่ง / ฟาเบร์ / ลูนาติก (และวิลโลว์ / คอนดอร์) **บนแผนที่**
6. ชนะมอนสเตอร์ทุ่งได้ Base EXP, Job EXP, Zeno, บางครั้งได้ยา — อยู่บนทุ่งต่อ มอนเกิดใหม่ ~4 วินาที
7. **เลือกบอสจากรายการ** แล้วเข้าฉากเทิร์นเบส ATB · เคลียร์ครั้งแรกได้โบนัสแต้ม / SP / เลเวล · ฟาร์มซ้ำได้จากหน้ารายการ

แผนที่: ลูกศร / WASD / D-pad หรือคลิกช่องทางเดิน · คลิกมอนเพื่อล็อกเป้า · สไปรต์โปร่ง `assets/chars/*_sprite.png` (สคริปต์ `tools/knockout_sprites.py`)

### เลเวล
- **Base Level** 1–99 และ **Job Level** 1–50
- `baseExpToNext(lv) = floor(80 * lv^1.65)` · `jobExpToNext(lv) = floor(50 * lv^1.55)`
- Base Up: โบนัสเลเวลเดิม (+100 HP, +30 MP, +5 ATK/MATK, +2 DEF/MDEF) และ **+10 แต้มสถานะ** (ปุ่ม HUD «แจกแต้ม»)
- Job Up: **+1 แต้มสกิล**
- `save.level` เท่ากับ Base Level เพื่อให้สูตรใน `stats.js` ใช้ต่อได้

### บอส 7 ตัว
เลือกบอสจากรายการ แล้วเข้าฉากเทิร์นเบส ATB ไม่ต้องเดินชนบนแผนที่บอส
- หน้า **เลือกบอส**: การ์ด 7 ใบ (อิโมจิ ชื่อ Lv สถานที่ HP/ATK/DEF) ★ ถ้าเคลียร์แล้ว · ปุ่ม **สู้** เริ่มไฟต์
- เคลียร์ครั้งแรกของแต่ละตัว: ได้ Base EXP พอขึ้น 1 เลเวล + แต้มโบนัส 60/80/100/120/140/160/180 + แต้มสกิล +2 + 500 Zeno (แจกแต้มจากปุ่ม HUD)
- ฟาร์มซ้ำ: +500 Zeno และฟื้น 25% แล้วกลับหน้ารายการบอส
- ชนะครบ 7 ตัวครั้งแรก = จอชัยชนะ แล้วเลือกบอสซ้ำได้

### ยา (ร้านยา + กระเป๋า HUD)
- ยาแดง ฟื้น 200 HP · 25 Zeno
- ยาส้ม ฟื้น 600 HP · 80 Zeno
- ยาขาว ฟื้น 1200 HP · 180 Zeno
- ยาฟ้า ฟื้น 80 MP · 60 Zeno
ใช้จากปุ่ม **กระเป๋า** บน HUD ได้ทั้งในเมือง ทุ่ง และระหว่างสู้

ร้านค้าชั้นสูง: ไอเทมแพง 800–1500 Zeno ต่อชนิด
แรงก์สกิล: โจมตี/ฮีล +15%/แรงก์ · ยูทิลิตี้ +4% · MP −5%/แรงก์ · CD −1 ตั้งแต่แรงก์ 4 (แล้วแปลงเป็นวินาทีจริง ×1.6)
ขึ้นสเตตัสคิดราคาตามช่วง (1–10 ใช้ 2 แต้ม, 11–20 ใช้ 3, …, 91–99 ใช้ 11)

### Soft / Hard DEF และตีบวก
- **Soft DEF / Soft MDEF** = ค่า DEF/MDEF เดิม (ฐาน + VIT/INT + ไอเทม + เลเวล) หักจากส่วน ATK/MATK แบบแบน
- **Hard DEF / Hard MDEF** มาจากตีบวกชิ้นสวมใส่เท่านั้น (หมวก เสื้อ รองเท้า ผ้าคลุม โล่) ชิ้นละ +0.7 ต่อระดับ เป็น % ลดดาเมจหลังหัก Soft
- ลำดับดาเมจ: raw → หัก Soft (พื้น 0) → คูณ (1 − Hard/100) → รวม → อย่างน้อย 1 · พิษไม่สนเกราะทั้งคู่
- บอส/มอน: Soft = DEF/MDEF เดิม, Hard = 0
- ตีบวก +1..+10 หน้า **ตีบวกอุปกรณ์** (จากร้านหรือหน้าสวมใส่) เก็บใน `save.refine[itemId]`
- โอกาส: +1–4 100% · +5–6 70% · +7–10 40% · ล้มเหลวไม่พัง/ไม่ลดระดับ เสียเฉพาะ Zeno
- ค่า Zeno: 100 / 200 / 300 / 400 / 600 / 800 / 1200 / 1600 / 2200 / 3000
- อาวุธตีบวกไม่ให้ Hard DEF — สมมติ +8 ATK และ +8 MATK ต่อระดับ

## PvP
ลานประลองเรียลไทม์ (เอนจินเดียวกับทุ่ง) — ไม่มีจอเทิร์น ATB
- **Local**: สองคนบนเครื่องเดียวกัน · P1 WASD + 1–6 · P2 IJKL + Q/U/E/R/T/Y · ทั้งคู่ฟันอัตโนมัติเมื่อชิด
- **ห้อง / โค้ดคำเชิญ**: ดวลเรียลไทม์กับ**บิลด์ของอีกฝ่าย** (อีกฝ่ายเดินเข้า + ฟัน/สกิลอัตโนมัติ) — ไม่ซิงก์อินพุตสดสองเครื่อง
แจกแต้ม 400 ไม่มีอุปกรณ์ · มีต้นไม้สกิลเล็ก (เริ่ม 4 แต้ม)

## โหมดห้อง PvP (ล็อบบี้สองเครื่อง / สองแท็บ)
โหมดห้องใช้เซิร์ฟเวอร์ Python (stdlib อย่างเดียว ไม่ต้อง pip)

```
cd RO-World
python3 server.py
```

แล้วเปิดเบราว์เซอร์ที่
- เครื่องนี้: `http://localhost:8765/`
- เครื่องอื่นบนไวไฟเดียวกัน: URL ที่เซิร์ฟเวอร์พิมพ์ว่า **LAN** เช่น `http://192.168.x.x:8765/`

ในเมนู PvP กด **สร้างห้อง** หรือ **เข้าห้อง** เลือกฮีโร่ แจกแต้ม แล้วกดพร้อม — แต่ละฝ่ายขึ้นลานประลองกับบิลด์ของเพื่อน (AI)

ถ้าเปิดเกมแบบ `file://` โหมดห้องจะใช้ไม่ได้ — ต้องรัน `python3 server.py`
